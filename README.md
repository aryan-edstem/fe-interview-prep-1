# fe-interview-prep

Frontend interview exercises built with React + TypeScript (strict). Each question lives on its own route.

## Requirements

- Node 22+
- pnpm 10

## Commands

```bash
pnpm install      # Install dependencies
pnpm dev          # Start the Vite dev server
pnpm build        # Type-check and build for production
pnpm test         # Run Vitest
pnpm lint         # Lint src with ESLint (zero warnings)
pnpm format       # Format with Prettier
```
